# مراجعة: Firecrawl MCP و Perplexity MCP
| | Firecrawl | Perplexity |
|---|---|---|
| الحزمة | `firecrawl-mcp` | `@perplexity-ai/mcp-server` |
| المستودع (حقل npm) | github.com/firecrawl/firecrawl-mcp-server | github.com/perplexityai/modelcontextprotocol |
| الإصدار المثبّت | `3.35.0` (2026-10-26، آخر إصدار ≥14 يوماً. الأحدث 3.38.0) | `1.3.0` (2026-09-25) |
| lifecycle scripts | لا يوجد | لا يوجد |
| المفتاح | `FIRECRAWL_API_KEY` (متغير بيئة مستخدم) | `PERPLEXITY_API_KEY` (متغير بيئة مستخدم) |
- **التسجيل دون `-e`:** لا نمرر المفتاح في `claude mcp add`، لأنه سيُكتب نصاً صريحاً في `~/.claude.json`. الخادم يرث المتغير من بيئة المستخدم.
- **التثبيت مشروط بالمفتاح:** بلا مفتاح يُتخطى البند.
- **تنبيه:** كلاهما يرسل الاستعلام إلى خدمة خارجية. قاعدة CLAUDE.md تمنع إرسال بيانات العملاء إليهما.
- **لم يُختبر هنا:** لا مفاتيح متاحة.
- **ملاحظة من المالك (2026-11-12):** تفعيل Perplexity API يحتاج شحن رصيد مسبق (مثلاً 10 دولار) قبل إصدار المفتاح. لا يوجد مستوى مجاني.
