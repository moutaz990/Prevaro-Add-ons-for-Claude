# Security — الأمان

**العربية**

- **ثغرة أمنية في إحدى الإضافات؟** افتح [Issue](https://github.com/moutaz990/Prevaro-Add-ons-for-Claude/issues) بعنوان واضح، **دون** نشر تفاصيل الاستغلال ولا أي مفتاح أو بيانات شخصية. اكتب أن عندك تفاصيل حساسة، وسنتفق على طريقة خاصة لإرسالها. إن ظهر لك زر **Report a vulnerability** في تبويب Security فاستخدمه بدل ذلك.
- **مفتاح تسرّب؟** ألغِه فوراً من الخدمة التي أصدرته (Google AI Studio، Typefully، Buffer)، ثم أنشئ غيره. إلغاء المفتاح عندهم هو ما يوقفه، لا حذف الرسالة.
- **ما نراجعه قبل النشر** مكتوب لكل مكوّن في [reviews/](reviews/): المصدر والإصدار، ما يُشغَّل، أين تذهب البيانات، وما لم يُختبر.
- لا تضع أي مفتاح أو كلمة سر أو بيانات عملاء في Issue أو Pull Request.

**English**

- **A security problem in one of the add-ons?** Open an [issue](https://github.com/moutaz990/Prevaro-Add-ons-for-Claude/issues) with a clear title, **without** exploit details, keys or personal data. Say that you have sensitive details and we will agree on a private way to send them. If the Security tab shows a **Report a vulnerability** button, use that instead.
- **A key leaked?** Revoke it at once at the service that issued it (Google AI Studio, Typefully, Buffer), then create a new one. Revoking it there is what stops it; deleting a message does not.
- **What is reviewed before publishing** is written per component in [reviews/](reviews/): source and version, what runs, where data goes, and what was not tested.
- Never put a key, a password or customer data in an issue or a pull request.
