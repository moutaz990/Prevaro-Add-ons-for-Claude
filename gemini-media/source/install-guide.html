Install & Connect

Gemini Images & Video extension for Claude Desktop: generate and edit images, generate video
Mac · Windows

Before you start

  • The Claude Desktop app, installed and up to date, on Mac or Windows. The extension does not work in the browser or on mobile.
  • A Gemini API key from Google AI Studio: aistudio.google.com/apikey
    It must belong to a project with billing enabled; image and video generation have no free tier.
  • Nothing else to install.

Install

  1. 1
    Download the file gemini-media-1.0.1.mcpb (the same file for Mac and Windows).
  2. 2
    Double-click it. Claude Desktop opens an install window; click Install.
    If nothing opens: in Claude Desktop go to Settings › Extensions › Advanced settings › Install Extension… and choose the file.

Connect your key

  1. 3
    Fill in the three fields:
    FieldWhat to enter
    Gemini API keyPaste your key
    Save files toThe folder where images and videos are saved. Default: Documents/Gemini Media
    Monthly spending cap (USD)The most you allow per month. Default: 30
  2. 4
    Save the settings and make sure the extension is enabled.

Try it

  1. 5
    Open a new chat and type: “Generate a square image of a white security camera on a grey background.”
    Claude asks permission to use the tool; allow it. The image is in the folder you chose.

If it does not work

ProblemFix
Nothing happens when you open the fileUse the Settings route in step 2, and make sure Claude Desktop is up to date
The tools do not appear in the chatQuit Claude Desktop and open it again
Mac shows a security warningSystem Settings › Privacy & Security, then allow
There is no Extensions page, or the install is refusedYour account is in an organization (Team or Enterprise) that restricts extensions. Ask the organization owner to allow it
Google rejects the keyCheck that it was copied in full and that its project has billing enabled

Remember: everything you generate is billed to your own key by Google: about $0.04 per image and about $0.10 per second of video.

Prompts, and any images you ask to edit, are sent to Google. Do not send client data or personal data.

To change the key or the monthly cap: Settings › Extensions › Gemini Images & Video › Configure
